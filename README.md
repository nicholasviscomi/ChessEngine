# The Beginnings of a Chess Engine
![image](/src/materials/startup.png)
Out of a love for chess, I wanted to a create a bot that can beat me. I currently have a chess engine with move annotations, sound effects, a full rule set, and an evaluation bar. This is one of my favorite projects and I will continue to work on improving the computer's abilities. I ran out of time to develop a strong search algorithm but this summer it should happen!
